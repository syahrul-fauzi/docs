## Context

Agen membutuhkan mekanisme jeda dan persetujuan manusia untuk aksi berisiko. Desain harus idempotent dan terobservasi.

## Decision

Gunakan event `interrupt {reason: human_approval}` dari runtime, kontrol via API `pause|resume|cancel`, audit semua aksi dan catat metrik resume/cancel. Terapkan idempotency untuk cancel/resume dan timeout handling.

## Alternatives

- Full workflow engine: berat untuk tahap awal.
- Tanpa persetujuan: meningkatkan risiko kebijakan.

## Consequences

- Pro: governance terjaga, observability kuat.
- Kontra: kompleksitas eksekusi meningkat.
