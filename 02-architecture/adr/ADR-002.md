## Context

Sistem mencakup beberapa domain: Analytics, Security, Access Control, Observability, Agent Runtime, Generative UI, Multimodal, Data Access. Tanpa pemisahan, batas tanggung jawab kabur dan coupling meningkat.

## Decision

Tetapkan bounded context per domain dan gunakan subgraph Mermaid untuk menandai konteks. Tarik dependensi lintas konteks via interface/ports dan hindari referensi langsung antar komponen yang berbeda konteks.

## Alternatives

- Monolithic context tunggal: sederhana tetapi riskan terhadap coupling dan skala.
- Micro-frontends/microservices granular: terlalu berat untuk tahap ini.

## Consequences

- Pro: kejelasan kepemilikan, isolasi perubahan, traceability.
- Kontra: perlu disiplin interface; dokumentasi tambahan dibutuhkan.
