## Context

Tim membutuhkan format diagram yang lintas-editor, mudah ditinjau di PR, dan dapat dirender di banyak tool tanpa vendor lock-in. Kebutuhan mencakup Sequence Diagram (UML), Component Diagram dengan bounded context, dan Dataflow Diagram level 0–2.

## Decision

Gunakan Mermaid (`.mmd`) untuk semua diagram arsitektur per fitur, dengan konvensi subgraph sebagai bounded context dan blok Legend untuk simbol. Sequence menggunakan `sequenceDiagram`, Component/DFD menggunakan `flowchart`.

## Alternatives

- PlantUML: kaya fitur UML, tetapi butuh server render/konfigurasi tambahan.
- Draw.io: GUI mudah, namun sulit ditinjau di PR (diff teks tidak optimal).
- Ascii diagrams: ringan, namun ekspresivitas terbatas.

## Consequences

- Pro: mudah di-review di PR, teks diffs jelas, integrasi lintas tool.
- Kontra: beberapa simbol UML tidak tersedia penuh; perlu konvensi internal.
