## Context

Diperlukan pelacakan kualitas via meta events (thumbs up/down) dan agregasi untuk analitik.

## Decision

Simpan event dengan tenant/user/time, agregasi di API, visualisasi di dashboard. Terapkan rate-limit dan verifikasi sesi.

## Alternatives

- Sentiment analysis ML: cakupan lanjutan.
- Simple logs: sulit dianalisis.

## Consequences

- Pro: feedback terstruktur, metrik mudah dipakai.
- Kontra: perlu guard manipulasi feedback.
