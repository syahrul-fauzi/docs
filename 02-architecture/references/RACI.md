# RACI Matrix

Versi: 1.0.0
Riwayat Perubahan:

- 1.0.0 (2025-12-05): Draft RACI awal.

## API Domain

- Responsible: Backend Engineer (Orchestrator)
- Accountable: Head of Platform
- Consulted: Security Engineer, Solutions Architect
- Informed: Product Owner
- QA: API QA Lead
- On-call: Backend On-call Rotation
- Eskalasi: P1 (immediate), P2 (4 jam), P3 (24 jam)
- Kontak: <api@sba.local>

## Data Domain

- Responsible: Data Engineer
- Accountable: Head of Data
- Consulted: Data Analyst, Data Steward
- Informed: Compliance Officer
- Kebijakan: RLS, Audit, Retensi
- Kontak: <data@sba.local>

## Web Domain

- Responsible: Frontend Developer
- Accountable: Head of Product
- Consulted: UX Designer, Accessibility Specialist
- Informed: Customer Success
- Kualitas: a11y, e2e coverage
- Kontak: <web@sba.local>

## Review Berkala

- Frekuensi: Quarterly
- Agenda: Perubahan struktur tim, SLA, dan proses eskalasi
