# Security Review Checklist

- Deps audit bebas high/critical
- Env production tervalidasi
- DB migrasi dan backup diverifikasi
- CI/CD dengan rollback dan notifikasi
- Monitoring, alerting, logging terpasang
- Load, security, integrasi testing lulus
- Dokumentasi operasional lengkap
- Disetujui ≥2 Senior Engineer
