# Panduan Pengguna: Mengunggah Lampiran di Chat

- Klik tombol `Attach files` atau seret-jatuhkan file ke area input.
- Batas ukuran: mengikuti `DEFAULT_STORAGE_CONFIG.maxFileSize`.
- Tipe yang diizinkan: sesuai `DEFAULT_STORAGE_CONFIG.allowedFileTypes`.
- Selama unggah, Anda dapat `Pause`, `Resume`, atau `Abort`.
- Setelah unggah selesai, pesan akan dikirim dengan lampiran.

## Troubleshooting

- "File terlalu besar": kompres atau pilih file lebih kecil.
- "Tipe tidak diizinkan": ubah format ke tipe yang diijinkan.
- Gagal unggah jaringan: gunakan `Resume` setelah koneksi stabil.
