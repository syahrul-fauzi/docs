# SBA-Agentic Style Guide

## 1. Kode (TypeScript/JavaScript)
- Gunakan PascalCase untuk Class dan Interface.
- Gunakan camelCase untuk variabel dan fungsi.
- Hindari penggunaan `any`, selalu gunakan typing yang ketat.

## 2. Penamaan File
- Gunakan kebab-case untuk nama file (contoh: `user-service.ts`).

## 3. Komentar & Dokumentasi
- Gunakan JSDoc untuk fungsi publik.
- Berikan komentar "Why" bukan "What" untuk logika yang kompleks.
