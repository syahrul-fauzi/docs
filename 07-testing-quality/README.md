# 07-testing-quality

Folder ini berisi strategi pengujian (QA), metrik kualitas, laporan pengujian, dan panduan validasi sistem.

## 👥 Audience
- QA Engineers
- Developers
- AI Agents (untuk memahami kriteria validasi)

## 📖 Konten Utama
- **[TESTING_STRATEGY.md](./TESTING_STRATEGY.md)**: Strategi pengujian menyeluruh (Unit, Integration, E2E) dan rencana validasi.
- **[QUALITY_METRICS.md](./QUALITY_METRICS.md)**: Metrik kualitas kunci, statistik pengujian, dan ambang batas (threshold).
- **[TRACEABILITY_MATRIX.md](./TRACEABILITY_MATRIX.md)**: Pemetaan persyaratan fungsional ke implementasi dan pengujian.
- **[A11Y_GUIDE.md](./A11Y_GUIDE.md)**: Panduan dan perbaikan aksesibilitas (WCAG 2.1 AA).

## 📂 Struktur Folder
- **[testing/](./testing/)**: Artefak pengujian, pembaruan E2E, dan catatan rilis pengujian.
- **[tests/](./tests/)**: Spesifikasi pengujian SLA, NFR, dan kriteria penerimaan.
