# Sistem Layout

- Grid: 12 kolom dengan gutter 16px; container widths: `sm 640px`, `md 768px`, `lg 1024px`, `xl 1280px`, `2xl 1536px`.
- Spacing baseline: 4px/8px; gunakan skala `xs, sm, md, lg, xl` yang selaras dengan tokens.
- Breakpoints: gunakan nilai di tokens untuk media queries dan komponen responsif.
- Pola: Sidebar + Content, Header + Content + Footer; dokumentasikan padding dan gap standar.
