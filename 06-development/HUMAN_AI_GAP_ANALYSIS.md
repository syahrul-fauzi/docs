# SBA-Agentic Human-AI Skills Gap Analysis

Dokumen ini menganalisis kesenjangan keterampilan antara kompetensi SDM tradisional dengan kebutuhan operasional sistem berbasis agen (Agentic System).

---

## 1. Perubahan Paradigma Peran

| Peran Tradisional | Peran Era Agentic | Perubahan Utama |
| :--- | :--- | :--- |
| **Software Engineer** | **Agentic Engineer** | Dari menulis kode prosedural menjadi merancang arsitektur reasoning dan prompt. |
| **SysOps / SRE** | **AgenticOps Specialist** | Dari memantau uptime server menjadi memantau akurasi logika dan drift perilaku agen. |
| **Data Analyst** | **Context Architect** | Dari membuat query statis menjadi mengelola Knowledge Base dan Vector Store untuk RAG. |

---

## 2. Identifikasi Kesenjangan Keterampilan (Gaps)

### 2.1 Technical Gaps
- **Prompt Engineering**: Kurangnya pemahaman tentang teknik CoT (Chain-of-Thought), ReAct, dan minimalisasi halusinasi.
- **Vector Database Management**: Kebutuhan akan keahlian dalam pgvector, embeddings, dan semantic search.
- **AI Observability**: Kurangnya pengalaman dalam memantau metrik non-deterministik.

### 2.2 Mindset Gaps
- **Delegasi vs Eksekusi**: Kebiasaan mengontrol setiap baris kode dibandingkan mempercayai agen untuk mengambil keputusan otonom.
- **Probabilistic Thinking**: Kesulitan menangani output AI yang tidak selalu identik untuk input yang sama.

---

## 3. Strategi Penutupan Celah (Closing the Gaps)

1.  **Pelatihan Intensif**: Workshop internal tentang Arsitektur SBA-Agentic dan LLM Fundamentals.
2.  **Pairing with Agents**: Mendorong developer menggunakan agen internal dalam alur kerja harian (dogfooding).
3.  **Recruitment Adjustment**: Menambahkan kriteria "AI Literacy" dan "Agentic System Design" dalam proses rekrutmen baru.

---

## 4. Roadmap Transformasi SDM

- **Fase 1 (Awareness)**: Sosialisasi visi SBA-Agentic dan demo kemampuan sistem.
- **Fase 2 (Upskilling)**: Sertifikasi internal untuk peran *Agentic Engineer* dan *Context Architect*.
- **Fase 3 (Integration)**: Penyesuaian struktur organisasi untuk mendukung kolaborasi Manusia-Agen yang optimal.
