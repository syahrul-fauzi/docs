# 05-api

Folder ini berisi dokumentasi API, skema JSON untuk integrasi, dan panduan penggunaan gateway tools SBA-Agentic.

## 👥 Audience
- Backend Developers
- Frontend Developers
- Integration Engineers
- AI Agents (untuk pemanggilan tool secara dinamis)

## 📂 Struktur Folder
- `schemas/`: Skema JSON untuk audit, event, dan tools.
- `endpoints/`: Detail endpoint API per modul.
